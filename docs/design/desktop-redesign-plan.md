## 2. 현재 평가 (critique)

- 방법: 두 평가를 서로 결과를 보지 않는 별도 에이전트로 나눠 돌렸다
  - A: 디자인 리뷰. playwright 로 1280 · 1440 × 900 에서 측정

## 3. 공통 체계

### 3.1 레이아웃 토큰 (lg 이상에서만 값이 생긴다)

```
--shell-max     1440px      홈 · discover · 상단 바 안쪽의 최대 폭 (지금 --app-col-w lg 값과 같다)
--gutter        40px        셸 좌우 여백. 로고 x = 본문 x = 40 (1440 초과 화면은 셸이 가운데로)
--detail-max    1120px      게시글 상세 본문 폭 (좌우 --gutter 별도)
--aside-w       360px       홈 지도 카드 · 상세 장소 카드 공통 폭 (lg 1024–1279 는 320)
--col-gap       48px        본문 열과 aside 사이 (lg 1024–1279 는 32)
--sticky-top    calc(var(--top-nav-space) + 24px)   aside sticky 기준선
```

- 지금의 `--app-col-w` · `--top-nav-space` 는 그대로 쓴다. 위 토큰은 리터럴로 흩어진 값(73rem, 300/360, px-5/6/10)을 대체한다
- **셸 폭은 모든 화면에서 같다.** 상단 바 로고가 화면마다 움직이지 않는 것이 본문 정렬보다 우선이다
- 상세 1120 은 셸 안에서 가운데 정렬한다. 1440 에서 상세 본문 x 는 160 이다
  - Airbnb 와 같은 선택이다(헤더는 넓고 상세는 좁음)
  - 홈 · discover 는 x=40 으로 로고와 맞는다

**12열 그리드는 두지 않는다.** 세 화면의 실제 구조는 전부 "본문 1fr + 고정 폭 aside" 또는 "고정 폭 패널 + 지도 1fr" 두 모양이다. 쓰지 않을 열 체계보다 두 모양을 이름으로 정한다.

| 모양 | 쓰는 곳 | 정의 |
|---|---|---|
| **Main + Aside** | 홈, 게시글 상세 | `grid-template-columns: minmax(0,1fr) var(--aside-w); gap: var(--col-gap)`. aside 는 `sticky top: var(--sticky-top)` |
| **Panel + Map** | discover | 패널 `clamp(440px, 40%, 600px)` + 지도 1fr. 지도만 고정, 패널 안쪽만 스크롤 |

### 3.4 검색창 — 홈 `HomeSearchBar` 가 기준

| 속성 | 값 |
|---|---|
| 높이 | 42 |
| 모양 | `rounded-full`, 테두리 없음 |
| 바탕 · 그림자 | `bg-background` · `shadow-float` |
| 아이콘 | Search 20, `text-muted-foreground`, 왼쪽 16 |
| 글자 | 16 |
| 옆 원형 버튼(필터 · 저장) | 42 원, `bg-background` · `shadow-chip`, 아이콘 20 |

- discover 닫힌 검색창 · `EventSearchBar` 는 이 모양으로 바꾼다
- 열린(입력 중) 상태의 `bg-muted` + 라임 제출 버튼은 기능 상태라 유지한다
- 높이 · 모서리 · 글자 크기는 닫힌 상태와 같게 맞춘다
- placeholder 문구는 화면 맥락이라 그대로 둔다. 홈 "Search", discover "Search places"

### 3.5 칩 — 홈 토픽 칩(`TOPIC_CHIP_*`)이 기준

| 상태 | 값 |
|---|---|
| 공통 | h 32, `rounded-full`, px 14, 15 / 500, 아이콘 16(있으면) |
| 기본 | `bg-background` + `shadow-chip`(흰 바탕 위에서도 보이게) |
| 선택 | `bg-brand`, 그림자 없음 |
| 누름 | `active:opacity-70` |

- **선택 가능한 칩은 전부 이 하나다.** discover 카테고리 칩(36h · 14/600 · `bg-muted`)과 필터 칩(28h · 12/600)을 여기로 모은다
- 상세 태그는 칩이 아니라 **배지**(`.pill-badge`, Topic 색)다. 누르는 물건이 아니므로 다른 모양을 유지한다
- 홈 지역 칩(38h)은 지도 카드 안의 큰 탭 대상이라 예외로 둔다. 바뀌는 것은 높이뿐이고, 그림자와 글자는 칩 체계를 따른다

### 3.6 카드 · 그림자 · 모서리 — `surface.md` 를 세 화면 전부에

| 대상 | 규칙 |
|---|---|
| 흐름 안의 카드 | `.surface-card` = 배경 + r20 + `shadow-card`. **테두리 없음** |
| 사진이 주인공인 카드(홈 가로 줄) | 사진 r16. 카드 바탕 · 그림자 없이 사진 + 아래 글자. Airbnb 방식 |
| 카드 안 사진 · 지도 | 바깥 r20 − 안쪽 여백 → r12(여백 8) / r8(여백 12). 썸네일 r0 금지 |
| 홀로 뜬 컨트롤 | `shadow-float`(검색창) · `shadow-chip`(칩 · 원형 버튼) |
| 큰 면(지도 영역) | r24, 그림자 없음 |
| 금지 | 검정 rgba 그림자 리터럴, Tailwind `shadow-sm/md/lg` 를 lg 화면 표면에 쓰기 |

- `--shadow-floating-button` 은 `--shadow-chip` 과 값이 같다. 하나로 합칠지는 구현 때 따로 묻는다(이름 변경이라)

### 4.3 discover

목표: 분할은 유지하고 정렬축 · 검색창 · 칩 · 카드를 공통 체계로 맞춘다. 이중 스크롤을 없앤다.

```
1440 × 900
┌ 상단 바 64 ───────────────────────────────────────────────────────────┐
│ reCree  ⌂  🗺                                            📷  🛍  👤 │
└──────────────────────────────────────────────────────────────────────┘
x=40 ┌ 패널 clamp(440, 40%, 600) ─┐ 24 ┌ 지도 (r24) ──────────────────┐ x=1400
y=80 │ [🔍 Search places ··][⚙][⌑]│    │                     [◎]      │ y=80
     │ [+][BTS][SVT][NCT] →        │    │                     [⛶]      │
     │ [🍴Food][☕Cafe][🏛Attr] →   │    │      Topic 색 마커           │
     │ ─────── 목록만 스크롤 ───── │    │                              │
     │ ┌ surface-card r20 ───────┐ │    │                              │
     │ │[썸네일r12] 배지 · 제목 ⌑ │ │    │                              │
     │ │           분류 · 지역    │ │    │                              │
     │ └─────────────────────────┘ │    │                              │
     │ ┌─────────────────────────┐ │    │                              │
     └─────────────────────────────┘    └──────────────────────────────┘ y=884
```

- **정렬축.** 패널 왼쪽 = 40(로고 선), 지도 오른쪽 = 1400(계정 아이콘 선). 위 · 아래 여백 16
  - 지금은 12 / 12 로 상단 바와 선이 안 맞는다
- **P0 수정.** 문서 높이 = 뷰포트. 패널 목록만 스크롤한다. 레이아웃 바깥 `min-h-[100dvh]` + lg 위 여백의 합을 없앤다
  - 원인 제거이지 discover 전용 분기를 넣는 것이 아니다
- **검색 줄:** 3.4 검색창 + 42 원형 버튼 2개(필터 · 저장)
- **칩 두 줄:** 토픽 줄(맨 앞 "+") · 카테고리 줄, 둘 다 3.5 칩. 줄 사이 8
  - 지금 단독 "+" 밑의 46px 빈 칸은 없어진다
  - 카테고리 칩은 아이콘을 유지하되 높이 · 글자 · 바탕은 토픽 칩과 같게
- **목록 카드:** 테두리 r18 → `.surface-card` r20, 안 여백 12, 썸네일 88 r8. 카드 사이 12
  - 저장 아이콘을 카드 안 오른쪽 위(여백 12)로 옮긴다. 지금은 카드 테두리에 걸쳐 잘린다
- 패널 폭: `clamp(440px, 40%, 600px)`. 1440 → 576, 1280 → 512
  - 지금 기준인 "패널 600 이상이면 목록 2열"은 이 폭에서는 발생하지 않는다. 1열로 고정하고, 2열 규칙은 지운다
- 지도 위 컨트롤(현재 위치 · 전체화면)은 오른쪽 위 유지. 장소 선택 플로팅 카드는 지금 규칙을 유지한다
